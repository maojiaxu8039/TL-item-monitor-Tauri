# TorchScan UI 优化审查建议

审查日期：2026-05-14

## 审查范围

本次审查覆盖主工作台外壳和主要功能页：

- 市场监控
- 物品追踪
- 价格分析
- 捡漏出货
- 提醒设置
- 火价分析
- 套利比价
- 策略管理
- AI 分析
- 数据监控
- 导入导出
- 帮助

整体判断：当前界面已经形成较统一的深色熔岩金属风，图标、导航和页面头部的品牌感较强。后续优化重点应放在布局密度、状态组件统一、浅色主题残留清理，以及局部页面的信息组织上。

## 高优先级

### 1. 侧边栏高度略撑

在 1280x720 这类常见桌面窗口尺寸下，侧边栏菜单项较多，当前菜单项高度、图标框和底部 logo 区域叠加后，靠下页面可能出现轻微滚动或顶部内容被挤掉。

建议：

- 将侧边栏菜单项高度从约 42px 收到 38-39px。
- 将侧边栏底部 logo 卡片高度略收紧。
- 保持图标可读性，但减少图标框内边距。
- 小高度窗口下优先展示完整导航，而不是让底部 logo 占太多空间。

相关位置：

- `src/index.css`
- `src/components/layout/Sidebar.tsx`

### 2. 页面标题与导航命名不一致

部分页面进入后标题与侧边栏名称不同，会造成轻微跳页感。

发现：

- 侧边栏为「物品追踪」，页面标题为「物价数据」。
- 侧边栏为「提醒设置」，页面标题为「预警规则」。

建议：

- 页面标题优先与侧边栏保持一致。
- 可将更具体的功能描述放入副标题中。

示例：

- 标题：「物品追踪」
- 副标题：「查看和管理游戏物品价格信息」

相关位置：

- `src/components/dashboard/ItemsPage.tsx`
- `src/components/dashboard/AlertsPage.tsx`

### 3. Loading 状态不统一

目前不同页面的加载状态样式不完全一致。有的页面只显示居中的 spinner，有的页面保留大面积空白，品牌感和稳定感不足。

建议：

- 抽出统一的 `LoadingState` 组件。
- 保持深色面板、金色边框、品牌图标或小型火焰图标。
- 文案按场景变化，例如「正在加载市场数据」「正在同步服务器状态」。
- 避免全页面空白中只放一个灰色 spinner。

相关页面：

- `src/components/dashboard/DealsPage.tsx`
- `src/components/dashboard/FirePriceComparePage.tsx`
- `src/components/dashboard/SettingsPage.tsx`
- 其他带 `Loader2` 的页面

### 4. AI 页面视觉与主风格略跳

AI 页面整体可用，但局部仍有偏紫或默认工具感：

- 发送按钮偏紫，与金色熔岩主题不够一致。
- 内部滚动条较亮，视觉存在感偏强。
- 错误 toast 接近输入框，容易显得拥挤。

建议：

- 将发送按钮改为品牌金橙渐变。
- 聊天区域滚动条改为细窄金色弱化样式。
- 错误 toast 避开底部输入区域，或统一走全局 toast 样式。
- 空状态图标可替换为当前金色品牌图标体系。

相关位置：

- `src/components/dashboard/AIAnalysisPage.tsx`

### 5. 火价分析筛选区信息密度偏高

火价分析页面的赛季选择、时间范围、自定义天数、指标卡和图表聚在同一视线范围内，工具栏略显拥挤。

建议：

- 将筛选条拆为「赛季对比」和「时间范围」两组。
- 自定义天数可以放入弹出层或折叠控件。
- 当前选中时间范围使用更明显的品牌态，而不是仅靠弱背景区别。

相关位置：

- `src/components/dashboard/FirePriceComparePage.tsx`

## 中优先级

### 6. 空状态图标偏灰

多个页面空状态仍以灰色 Lucide 图标为主，与当前金色发光图标体系不完全一致。

建议：

- 为常见空状态建立品牌图标变体。
- 空状态面板保持弱金色边框或轻微辉光。
- 图标、标题、副文案三者间距统一。

相关页面：

- 提醒设置
- 套利比价
- 策略管理
- 数据监控

### 7. 导入导出页宽屏利用率不足

导入导出页面当前内容集中在中间窄列，宽屏下右侧留白较多。

建议：

- 改成左右两列：左侧导入，右侧导出。
- 数据库备份、CSV 导入导出分别成组。
- 对危险操作或覆盖操作增加更明显的确认语义。

相关位置：

- `src/components/dashboard/ImportExportPage.tsx`

### 8. 圆角规格需要继续收敛

当前界面中仍能看到 `rounded-xl`、`rounded-2xl`、`rounded-full` 等混用。设计规则里更偏 8px 卡片半径，过大的圆角会让工具型桌面应用显得偏移动端。

建议：

- 面板、卡片、弹窗主体统一到 8px。
- 标签、状态点、开关等功能性圆形元素可以保留 full radius。
- 聊天气泡等特殊场景允许单独保留较大圆角。

相关位置：

- `src/index.css`
- `src/components/dashboard/*`

## 低优先级

### 9. 顶部栏在窄窗口下信息偏多

顶部栏包含品牌、当前页面、赛季模式、火价、刷新、网络、通知、设置和窗口控制。窄窗口下会显得拥挤。

建议：

- 小宽度下「网络」「通知」变为纯图标。
- 火价 chip 可缩短为数值 + 单位。
- 页面标题区域可减少左边距。

相关位置：

- `src/components/layout/TopBar.tsx`
- `src/index.css`

### 10. 模态框样式可再统一

策略、套利、提醒等页面存在多个本地实现的 modal。它们大体可用，但标题区、按钮区、边框、阴影和背景遮罩可以更一致。

建议：

- 优先复用 `src/components/ui/dialog.tsx`。
- 模态标题区统一图标、标题、副标题位置。
- 操作按钮统一右下角排列。

## 建议执行顺序

1. 先修侧边栏高度和页面标题一致性。
2. 抽统一 `LoadingState` 和 `EmptyState` 品牌样式。
3. 调整 AI 页面发送按钮、滚动条和错误提示。
4. 重排火价分析筛选区。
5. 优化导入导出宽屏布局。
6. 最后做圆角、modal、顶部栏响应式等细节收敛。

## 验证建议

每轮调整后至少检查以下窗口尺寸：

- 1280x720
- 1440x900
- 1200x800，接近 Tauri 默认窗口

每轮调整后运行：

```bash
npm run typecheck
npm run vite:build
```

如果改动涉及 Tauri 图标、窗口、托盘或通知，再额外运行对应平台打包检查。
